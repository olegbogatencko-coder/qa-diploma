# Дипломный проект: Автоматизация тестирования сервиса покупки туров

## Описание
Данный проект содержит автоматизированные тесты для веб-сервиса "Путешествие дня", который позволяет купить тур с помощью дебетовой карты или в кредит. Приложение взаимодействует с эмулятором банковских сервисов и сохраняет данные в СУБД MySQL.

## Стек технологий
*   **Java 11** (или 17)
*   **Gradle**
*   **Selenide** (UI-тесты)
*   **JUnit 5**
*   **JDBC** (для проверки БД)
*   **Allure** (для отчетов)
*   **Docker & Docker-compose** (для развертывания окружения)

## Запуск проекта

### 1. Подготовка окружения
Убедитесь, что у вас установлены:
*   Docker Desktop
*   Java (JDK 11 или 17)

### 2. Запуск контейнеров
