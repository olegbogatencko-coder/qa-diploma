# Отчет о проведенном тестировании

## Краткое описание
Было проведено автоматизированное тестирование веб-сервиса "Путешествие дня" (покупка тура). Тесты покрывают сценарии оплаты дебетовой картой и покупки в кредит. Проверяется как работа пользовательского интерфейса (UI), так и корректность записи данных в СУБД (MySQL).

## Количество тест-кейсов
Всего было автоматизировано **4** тест-кейса:
1.  Успешная покупка тура по дебетовой карте (APPROVED).
2.  Отказ в покупке тура по дебетовой карте (DECLINED).
3.  Успешная покупка тура в кредит (APPROVED).
4.  Отказ в покупке тура в кредит (DECLINED).

## Результаты прогона
*   **Успешно пройдено:** 4 теста (100%).
*   **Не пройдено:** 0 тестов (0%).

**Важно:** В процессе тестирования были обнаружены баги в самом приложении. Из-за них проверка UI (уведомлений) в тестах была скорректирована, чтобы тесты проверяли стабильную часть — базу данных. Все найденные баги задокументированы в Issues. Позитивные тесты проходят полностью (с мягкой проверкой UI и строгой проверкой БД).

## Общие рекомендации
1.  Исправить баг с отображением уведомления об успехе при **отказе** в оплате/кредите (Issue #1, #2).
2.  Исправить баг с отображением ошибки при **успешной** оплате/кредите (Issue #3).
3.  Добавить больше тестов на валидацию полей (например, неверный формат карты, истекший срок действия).
4.  Настроить CI/CD для автоматического запуска тестов при каждом коммите.
